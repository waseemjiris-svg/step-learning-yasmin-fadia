# step-learning-yasmin-fadia

<div dir="rtl" align="right">

**צעד אחר צעד בלמידה מרחוק** — כלי לתלמידים ולצוות החינוכי, במסגרת הפרויקט היישומי בחינוך של פאדיה ויאסמין.

האתר מציג חמש שאלות דירוג ושאלה פתוחה, סיכום אישי עם הצעות, טעינת קובצי תשובות לסיכום קבוצתי ומשוב על הכלי. זהו כלי מקומי למיפוי ולשיחה עם הצוות; הוא אינו שאלון מחקרי מתוקף, אבחון או מדד להוכחת שינוי בהישגים.

## הפעלה מקומית

נדרש דפדפן עדכני. אין צורך בהתקנת חבילות או בשלב בנייה. מתוך תיקיית המאגר, עם Python 3 מותקן:

</div>

```sh
python -m http.server 8000 --bind 127.0.0.1
```

<div dir="rtl" align="right">

פתחו את [האתר המקומי](http://127.0.0.1:8000). לעצירת השרת לחצו `Ctrl+C`. השתמשו בכתובת המקומית הזו, או ב־HTTPS באחסון חיצוני, כדי לאפשר את פעולות הדפדפן ליצירת מזהה ולהעתקת משוב.

## מבנה המאגר

| קובץ | תפקיד |
| --- | --- |
| `index.html` | ממשק בעברית מימין לשמאל, עיצוב והנחיות שימוש |
| `app.js` | השאלון, הסיכום האישי, ייצוא וטעינת תשובות ומשוב |
| `.nojekyll` | קובץ סימון להגשת קבצים סטטיים באחסון שתומך בו |
| `scripts/check-site.mjs` | בדיקות מבניות ותחביר ללא חבילות חיצוניות |

## תשובות ופרטיות

- הקוד מעבד את התשובות בזיכרון הדפדפן. אין בקוד שרת תשובות, מסד נתונים, שירות אנליטיקה או שליחה אוטומטית. אין להסתמך על שמירת תשובות לאחר רענון או סגירת הדף.
- הורדת תשובות יוצרת במכשיר קובץ `learning-response-*.json`; המשתמש מחליט אם ואיך להעביר אותו לצוות. דרך ההעברה עשויה לזהות את השולח בפני המורה.
- אין להזין שמות או מידע מזהה ורגיש. אין להעלות קובצי תשובות או משוב למאגר GitHub; כללי ההתעלמות בקובץ `.gitignore` מסייעים למנוע הוספה בטעות.
- בעת טעינת קבצים, הסיכום מתבסס על ערכי דירוג 1–5 בלבד. דילוג נשמר כ־`null`, ו״לא רלוונטי״ כ־`"na"`; שניהם מוחרגים מהממוצע. מספר המשיבים מוצג לכל פריט בנפרד. קבצים בעלי אותו מזהה נספרים פעם אחת בכל טעינה.
- אין ציון כולל. ממוצע הפריט ומספר תשובות 1–2 הם תיאוריים בלבד.

## בדיקות לפני שינוי

להרצת הבדיקות נדרש Node.js 24:

</div>

```sh
node scripts/check-site.mjs
```

<div dir="rtl" align="right">

הבדיקה מזהה שגיאות תחביר ב־JavaScript, הפניות לקבצים מקומיים חסרים, מזהי HTML כפולים והפניות רכיבים שאינן תואמות את הדף. GitHub Actions מריץ אותה בבקשות מיזוג ובעדכוני `main`, בהרשאת קריאה למאגר. הפעולה אינה מפרסמת את האתר.

בדיקה זו אינה בדיקת דפדפן. לפני שינוי בממשק או בחישובים יש לבדוק ידנית גם בטלפון: מעבר בין לשוניות, מענה חלקי ו״לא רלוונטי״, הורדה וטעינה של קובצי בדיקה סינתטיים, טיפול בכפילויות ובקובץ לא תקין, הדפסה והעתקת משוב. יש לוודא שהעברית, כיוון הכתיבה והשימוש במקלדת נשמרים.

## הצעת שינויים

עבדו בענף נפרד ופתחו בקשת מיזוג עם תיאור קצר ותוצאות הבדיקה. שמרו על הייחוס לפרויקט, על ערכים חסרים ועל מגבלות הפרשנות החינוכית. השתמשו בנתוני דמה בלבד לצורך בדיקות וצילומי מסך. הגדרות אחסון וכתובת האתר מנוהלות בנפרד מהקוד במאגר.
